# Industria 4.0 Inventory Pro

Crear una aplicación profesional de gestión de inventario para una empresa tecnológica enfocada en desarrollo de soluciones Industria 4.0 basadas en IoT.

La aplicación debe ser moderna, profesional, escalable y con diseño UI/UX empresarial.

Estructura general del sistema:

1. Módulos principales:

- Inventario de Equipos de Laboratorio

- Inventario de Componentes Electrónicos

- Inventario de Herramientas

- Inventario de Activos Tecnológicos

- Inventario de Proyectos en Desarrollo

2. Campos del inventario:

Información General:

- Código único

- Nombre del equipo/componente

- Categoría

- Subcategoría

- Descripción técnica

- Imagen del producto

Información Técnica:

- Marca

- Modelo

- Número de serie

- Especificaciones técnicas

- Voltaje

- Potencia

- Comunicación (I2C, SPI, UART, etc.)

- Compatibilidad

Información Administrativa:

- Proveedor

- Fecha de compra

- Costo unitario

- Cantidad

- Stock mínimo

- Ubicación física

- Responsable asignado

- Estado (Disponible, En uso, Mantenimiento, Dañado)

Información Operativa:

- Proyecto asignado

- Área asignada

- Fecha de ingreso

- Fecha última actualización

- Observaciones

3. Dashboard principal con métricas:

- Total de activos

- Total equipos laboratorio

- Total componentes electrónicos

- Equipos en uso

- Equipos en mantenimiento

- Stock bajo

- Valor total del inventario

- Inventario por categoría (gráficas)

4. Funcionalidades requeridas:

- CRUD completo (Crear, Editar, Eliminar)

- Buscador inteligente

- Filtros por categoría

- Filtros por estado

- Filtros por ubicación

- Alertas de stock bajo

- Alertas de mantenimiento

- Sistema de etiquetas

5. Diseño UI:

- Diseño moderno estilo empresa tecnológica basada en los colores del logo adjunto

- Dashboard con tarjetas visuales

- Gráficas profesionales

- Interfaz limpia y profesional

- Responsive (PC y móvil)

6. Extras profesionales:

- Exportar a Excel

- Exportar a PDF

- Control de usuarios

- Roles:

  - Administrador

7. Estructura visual:

- Menú lateral

- Dashboard principal

- Módulo Inventario

- Reportes

- Configuración

El diseño debe ser elegante, profesional y enfocado a empresa tecnológica de Industria 4.0.
